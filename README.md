Welcome to **Hatty's News**, a high-intelligence, real-time crypto news terminal designed for traders, investors, and enthusiasts who need to stay ahead of the curve.

## 🚀 Why I Built This
In the fast-paced world of cryptocurrency, information is power. I built **Hatty's News** because I wanted a centralized, "terminal-style" dashboard that cuts through the noise. Instead of jumping between a dozen different tabs, this app brings the most critical market data—headlines, sentiment, and prices—into one sleek, high-performance interface.

It's designed to feel like a professional trading tool, focusing on speed, readability, and real-time updates.

---

## ✨ Key Features

### 📡 Multi-Source RSS Aggregator
- **Real-Time Feeds**: Aggregates news from top-tier sources like CoinTelegraph, CoinDesk, Bitcoin Magazine, and Decrypt.
- **Smart Proxying**: Uses custom Netlify Functions to bypass CORS restrictions and restrictive firewalls (like CryptoSlate), ensuring your news is always online.
- **Categorized View**: Filter news by category (Bitcoin, Altcoins, NFTs, Mining, etc.) or search for specific keywords.

### 📊 Market Sentiment (Fear & Greed Index)
- **Instant Pulse**: A dedicated "Gauge" button that fetches the latest **Crypto Fear & Greed Index** data.
- **Educational Tool**: Explains what the current sentiment means for the market, helping you make more informed decisions.

### 📈 Live Crypto Ticker
- **Marquee Ticker**: A real-time price ticker powered by LiveCoinWatch, keeping you updated on the top coins and biggest movers without leaving the page.

### 🎨 Premium Design & UX
- **Terminal Aesthetic**: A dark, high-contrast UI inspired by professional financial terminals.
- **Custom Splash Screen**: Features a custom `newsworld.gif` background for a unique branding experience.
- **Hatty's Network**: A built-in dropdown menu connecting you to the broader Hatty ecosystem (Learn With Hatty, Token-Tokens, etc.).
- **Responsive & Fast**: Built with React 19 and Vite for lightning-fast performance across all devices.

## 🛠️ Tech Stack
- **Frontend**: [React 19](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Backend (Serverless)**: [Netlify Functions](https://www.netlify.com/products/functions/)
- **RSS Parsing**: [rss-parser](https://www.npmjs.com/package/rss-parser)
- **Build Tool**: [Vite](https://vitejs.dev/)

---

## 📦 Deployment to Netlify
This project is optimized for **Netlify**. To deploy:
1. Push the code to your GitHub repository.
2. Connect the repository to Netlify.
3. Netlify will automatically detect the `netlify.toml` file and configure the build settings and serverless functions.
